# SPIP-Eviden

Aplikasi checklist & monitoring eviden SPIP.

## Fitur
- Login Google
- Dashboard progress per unit & periode
- Checklist parameter lengkap (Grade A-E, kriteria, penjelasan)
- Upload eviden via Google Drive
- Verifikasi eviden
- Log aktivitas

## Teknologi
- **Frontend**: HTML + Tailwind CSS + Vanilla JS
- **Backend**: Google Apps Script
- **Database**: Google Sheets
- **Storage**: Google Drive
- **Hosting**: GitHub Pages

## Setup
1. Deploy Apps Script sebagai Web App
2. Copy URL Web App ke `assets/js/config.js` sebagai `API_URL`
3. Isi `GOOGLE_CLIENT_ID` di `config.js` dan `index.html`
4. Push ke GitHub → aktifkan GitHub Pages
